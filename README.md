# Signal-catcher

### A signal catcher for android.

## Includes:
1. Cell Towers
2. Wi-Fi signals
3. Bluetooth devices
4. Satellites and GPS
5. Light levels, pressure and magnetics
6. Messages and downloads
7. System changes

Simple, no bloat, easy to use and fun to watch signal catcher. 

Written in kotlin.

Over 1500 lines of code!

## Specs:
1. Minimum 750kb storage, 900kb recommended
2. Whole phone access (it only reads, doesn't write: needs SMS and restricted settings on to work)
3. A phone / android simulator
